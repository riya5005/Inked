Inked : code you wrote yourself, like handwriting.


A coding practice platform where you can't paste your code. You write every line yourself.

The idea

Most practice sites let you paste in a solution from an AI tool, hit submit, and get a green tick without learning anything.

Typewright blocks pasting and drag-and-drop in the editor, and records how your solution gets written. If you want the tick, you have to solve the problem yourself.

How it works
Paste and drop are disabled in the code editor
Your typing is recorded, so you can replay how you built the solution
Code runs in a sandbox against hidden test cases
A note on honesty

No browser-based tool can stop a determined cheater. Typewright aims to make shortcuts inconvenient, not impossible, and to keep the easy path as the honest one.

Status

Early idea stage. Nothing is built yet.
